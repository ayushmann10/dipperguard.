01 / The idea

A simple concept with a meaningful purpose.

Bright high-beam headlights can make it harder for an oncoming driver to see clearly. An automatic dipper concept aims to reduce glare by changing to low beam when an approaching vehicle is detected.

◉

Detect

The existing prototype uses a light-dependent resistor (LDR) circuit to respond to changes in light intensity.

⌁

Decide

The circuit's threshold and switching arrangement determine when the model changes its lighting state.

✧

Dip

The model demonstrates a change between high-beam and low-beam light outputs.

05 / Honest engineering

Prototype today. Further research tomorrow.

What this project shows

A low-voltage educational model of light sensing and automatic switching, supported by a website and interactive software simulation.

What it does not claim

This website does not measure live sensor data, detect actual vehicles, use AI, or control a road vehicle. The simulation is not a safety-certified driving system.

Safety note: Keep the physical project as a low-voltage demonstration. Do not connect this prototype to a real vehicle's headlight wiring.
06 / FAQ

Frequently asked questions

Does this website connect to my actual model?

No. It is a standalone digital showcase and simulation. Your existing hardware stays unchanged.

Will it work on a mobile phone?

Yes. The layout adapts to phone screens. On supported browsers, you can also install it as a web app after it is hosted over HTTPS.

Is hosting free?

The site is designed for free static hosting, such as GitHub Pages on a public repository. A custom domain is optional and not included.

Is the simulation AI?

No. It is a rule-based JavaScript simulation. It is best presented honestly as an interactive demonstration, not as AI or live vehicle detection.
